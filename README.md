# CaseFlow — AI-Powered Patient Case-Taking System

**SIH26047**

CaseFlow is an AI-powered pre-consultation patient case-taking
system designed to reduce the time doctors spend collecting
patient history in high-volume healthcare settings.

## Overview

CaseFlow interacts with patients through voice, text, and touch,
uses adaptive questioning to collect relevant clinical history,
and converts patient responses and previous medical documents
into a structured, doctor-ready summary.

The system is designed as a shared, kiosk-first experience for
elderly, multilingual, low-literacy, and first-visit patients.

## Key Features

- 🏥 Patient registration and consent
- 🗣️ Multilingual patient interaction
- 🤖 AI-powered adaptive questioning
- 📝 Clinical information extraction
- 📄 Medical document OCR
- 🕐 Patient history timeline
- ⚠️ Hybrid red-flag detection
- 👨‍⚕️ Doctor dashboard and verification
- 🌿 Configurable AYUSH mode
- 🔗 Mock ABDM / FHIR integration

## Technology Stack

- **Frontend:** React + Tailwind CSS
- **Backend:** Python + FastAPI
- **Database:** SQLite
- **AI:** Modular AI service
- **OCR:** Modular OCR service

## Scope

CaseFlow is a clinical documentation and decision-support tool.
It does **not** function as an autonomous diagnostic system.
The doctor retains final authority over the patient record.
